# AUTHENTICATION

A playful frustration-style login page built with HTML, CSS, and JavaScript.

## Features

- Clean **AUTHENTICATION** heading
- Small prompt: **enter your id and password**
- ID and password input fields
- Fast cursor-dodging **LOGIN** button
- Clicking the button displays:
  > you are logined in less attempts wanna try again?
- Fully front-end and self-contained

## Run locally

Open `index.html` in any modern web browser.

## Files

- `index.html` — page structure
- `style.css` — visual design
- `script.js` — button movement and interaction

## Note

This is a front-end demo. It does not store or transmit login credentials.
